What's New in 1.2.x

  • Refreshed app icon — New design featuring stacked windows with a cursor.
  • Settings window — A proper preference window (General + About tabs) replaces the menu-bar-only toggles. Configure modifier keys, per-feature switches, middle-click action, and launch-at-login from one place.
  • Cleaner Features section — The modifier picker is folded into the Features list with a chip-style selector. The redundant menu-bar "Enabled" toggle is gone — uncheck all modifier keys (or all per-feature switches) to disable AnyDrag.
  • Middle-button tile by direction — Press the middle mouse button on any window and drag in a direction to tile it: up = full screen, down = centered 85%, left/right = halves, corners = quarters. A translucent live preview shows the target zone before you release.
  • Middle-button drag — Optional alternative to modifier+drag: press and hold the middle mouse button to move any window, no modifier required. Off by default; enable from Settings. (Thanks to @goxq)
  • Option + modifier drag to tile — If your AnyDrag modifier is not Option (e.g. fn, Command, Control), you can now hold Option as an extra key to trigger macOS native window tiling while dragging. (Thanks to @goxq)
  • Sparkle auto-update — AnyDrag checks for updates automatically via Sparkle.
  • Bug fixes and stability improvements

1.2.x 更新内容

  • 全新应用图标 — 全新设计的图标:叠层窗口与光标的组合。
  • 设置窗口 — 新的设置窗口(通用 + 关于 两个标签页)取代了之前只能在菜单栏中切换的方式,可在一处调整修饰键、各功能开关、鼠标中键动作,以及登录时启动。
  • 更清晰的"功能"分区 — 修饰键选择器并入"功能"列表,采用 chip 样式选择。原本菜单栏中的"启用"总开关已移除——取消勾选所有修饰键(或所有功能开关)即可禁用 AnyDrag。
  • 鼠标中键方向平铺 — 在窗口上按住中键并朝某个方向拖动即可平铺:上 = 全屏,下 = 居中 85%,左右 = 半屏,四角 = 四分之一屏。释放前会显示半透明的目标区域预览。
  • 鼠标中键拖动窗口 — 修饰键+拖动之外的可选方案:直接按住鼠标中键即可移动窗口,无需修饰键。默认关闭,可在设置中启用。(感谢 @goxq 贡献)
  • Option + 修饰键拖动平铺 — 如果 AnyDrag 的修饰键不是 Option(如 fn、Command、Control),现在可以额外按住 Option 键,在拖动窗口时触发 macOS 原生窗口平铺功能。(感谢 @goxq 贡献)
  • Sparkle 自动更新 — AnyDrag 现在通过 Sparkle 自动检查更新。
  • Bug 修复与稳定性改进
