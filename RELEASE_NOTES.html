What's New in 1.3.0

  • In-app language picker — Switch the AnyDrag UI between Follow System, English, and 简体中文 from Settings → General. Takes effect immediately, no relaunch.
  • Settings reorganized into three tabs — General (language, accessibility permission, launch at login, diagnostics), Advanced (modifier keys, feature toggles, middle-click action), and About. Window width stays stable while you switch tabs.
  • Accessibility permission visible in Settings — General tab shows a green dot when authorized, or a one-click Authorize button that opens System Settings when not. The status updates live as you toggle the permission.
  • Revoking AX permission no longer freezes the system — In earlier versions, toggling off AnyDrag's Accessibility permission in System Settings would lock the entire macOS input pipeline (no mouse, no keyboard, hard reboot required). AnyDrag now detects the revocation and tears the event tap down cleanly. When permission is granted again it restarts on its own.
  • More Apps by Author — New menu-bar item linking to xueshi.dev for quick access to other apps.
  • Middle-button tile drag is cancellable — During a middle-button tile-by-direction gesture, drag back into the small dot at the press origin to cancel — even after passing the trigger threshold.
  • Diagnostics always visible — The "title-bar Y offset" knob (useful for apps like WeChat with non-standard top bars) and the synthesized-click marker now live under Settings → General → Diagnostics by default. Values persist across launches, with a Reset button to restore the default 3 px.
  • Bug fixes and stability improvements

1.3.0 更新内容

  • 应用内语言切换 — 在「设置 → 通用」中可在「跟随系统 / English / 简体中文」之间切换 AnyDrag 界面语言,切换立即生效,无需重启。
  • 设置页重新组织为三个标签页 — 通用(语言、辅助功能权限、登录时启动、诊断)、高级(修饰键、功能开关、鼠标中键动作)、关于。切换标签时窗体宽度不再变化。
  • 设置页中可直接看到辅助功能权限状态 — 通用页显示绿点 + 「已授权」,未授权时显示「授权」按钮一键跳转系统设置;权限变化实时刷新。
  • 撤销辅助功能权限不再导致系统冻结 — 之前在系统设置里关闭 AnyDrag 的辅助功能权限会让整个 macOS 输入管道死锁,鼠标键盘全部失灵,只能强制重启。现在 AnyDrag 会立刻检测到权限撤销并干净地拆除事件 tap;重新授权时会自动恢复。
  • 菜单栏新增「作者的更多应用」入口 — 跳转至 xueshi.dev,方便查看作者的其他应用。
  • 中键平铺手势可取消 — 按住中键进行方向平铺时,即使已经越过触发阈值,把光标拖回起点附近的小圆点上即可取消本次平铺。
  • 诊断设置默认可见 — 「标题栏 Y 偏移」(对微信等顶栏非标准的应用有用)和「模拟点击标记」现在默认显示在「设置 → 通用 → 诊断」中,设置会持久保存,并新增「重置」按钮可还原为默认的 3 px。
  • Bug 修复与稳定性改进
